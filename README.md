# AI Search & Pathfinding

An AI search and pathfinding project using classic search algorithms to solve state-space and multi-objective problems.

## Algorithms Implemented

- Depth-First Search (DFS)
- Breadth-First Search (BFS)
- Uniform Cost Search (UCS)
- A* Search

## Features

- Implements uninformed and informed search strategies
- Solves pathfinding problems across complex state spaces
- Handles search problems involving multiple objectives
- Uses heuristics to improve search efficiency
- The solutions are compared based on the path cost and search performance.

## Technologies

- Python
- Artificial Intelligence
- Search Algorithms
- Heuristic Search
- Data Structures & Algorithms

## What I Learned

The project made me familiar with search algorithms, with designing heuristics for the A* search algorithm and with setting up and solving state-space problems, and with the tradeoffs involved with optimizing solutions versus computational effort.
